# Research Project Template (Agent-Optimized)

## Overview
This repository contains the research materials, implementation code, and documentation for [Project Name]. It follows a strict **Agent-Based Workflow** designed for autonomous AI researchers (PI, PhD-Theory, PhD-Algo, etc.).

## Directory Structure

- **`/papers`**: Academic papers (PDFs) and Markdown analysis.
- **`/code`**: Implementation source code.
- **`/data`**: Datasets (Raw/Processed).
- **`/docs`**: Workflow guides (`workflow_guide.md`).
- **`/search_logs`**: Timestamped logs of Zotero/Web searches.
- **`/reports`**: Formal reports (e.g., Typst/LaTeX).
- **`/progress`**: Daily progress notes.
- **`/templates`**: Templates for reports and visualizations.
- **`/demo`**: End-to-end demonstration scripts.

## Core Operational Files
- **`task_queue.md`**: Central task management board.
- **`escalation_protocol.md`**: Decision tree for when to ask for human help.
- **`skill.md`**: Meta-learning log for the AI agents.
- **`research_plan.md`**: High-level strategic roadmap.

## Getting Started (for Agents)
1.  **Read the Guide**: Start with `docs/workflow_guide.md`.
2.  **Check the Queue**: Read `task_queue.md` for the next `[Pending]` task.
3.  **Search First**: Before asking, check `search_logs/` and `skill.md` to avoid redundant work.
