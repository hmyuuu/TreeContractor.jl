# Analysis: Approximating clique-width and branch-width

**Paper ID:** [Oum 2006]
**Authors:** Sang-il Oum and Paul Seymour
**Year:** 2006
**Journal:** Journal of Combinatorial Theory, Series B

## Mathematical Definitions

### Rank-Width
Let $G$ be a graph. A **rank-decomposition** of $G$ is a pair $(T, L)$ where $T$ is a subcubic tree (degree $\le 3$) and $L$ is a bijection between the leaves of $T$ and the vertices $V(G)$.
For each edge $e \in E(T)$, removing $e$ partitions the leaves into two sets $(A, B)$.
The **width** of an edge $e$ is defined as the rank of the adjacency matrix cut $M_{A,B}$ over the field $GF(2)$, denoted as $\text{rank}(M_{A,B})$.
The **width of the decomposition** is the maximum width over all edges $e$.
The **rank-width** of $G$, denoted $rw(G)$, is the minimum width over all possible rank-decompositions.

### Relation to Clique-Width
Clique-width ($cw(G)$) is another width parameter based on graph construction operations.
**Theorem:** For any graph $G$,
$$ rw(G) \le cw(G) \le 2^{rw(G)+1} - 1 $$
This implies that a class of graphs has bounded rank-width if and only if it has bounded clique-width.

## Algorithmic Content

### Approximation Algorithm
The paper provides an algorithm that, for a fixed $k$, either:
1. Outputs a rank-decomposition of width at most $3k+1$ (later improved in subsequent papers).
2. Certifies that the rank-width is greater than $k$.

**Complexity:** $O(n^4)$ originally, but subsequent improvements (Oum 2008) brought this down to $O(n^3)$.

### Implementation Challenges
- **Matrix Operations:** Requires efficient handling of binary matrices and rank calculations (Gaussian elimination).
- **Tree Structures:** Managing dynamic tree splits and merges during the approximation steps.

## Tensor Network Applications

### Connection to Tensor Rank
- The definition of rank-width relies on the matrix rank of the adjacency matrix cut. This is structurally identical to the **Schmidt rank** or **bond dimension** in a tensor network state (like MPS or PEPS) if we view the graph as a tensor network where edges represent contracted indices.
- A rank-decomposition tree naturally corresponds to a **pairwise contraction order** (or a tree tensor network).
- Minimizing rank-width is equivalent to minimizing the maximum bond dimension required to represent the graph state (Graph State) in a tree-like tensor network structure.

### Potential Use Cases
- **Contraction Ordering:** Instead of using treewidth on the line graph (which optimizes for tensor size assuming dense tensors), rank-width optimizes for the *rank* of the cut. This is more relevant when tensors are low-rank or when we can use SVD to truncate.
- **Quantum Circuit Simulation:** For circuits dominated by CNOT gates (which correspond to GF(2) operations), rank-width might provide better bounds than treewidth.

## Critical Evaluation

### Novelty
- Introduced rank-width as a more mathematically tractable alternative to clique-width.
- Proved the first polynomial-time approximation for clique-width (via rank-width).

### Impact
- Seminal paper that spawned the field of rank-width and boolean-width research.
- Provided the theoretical foundation for "rank-structured" graph algorithms.

### Open Questions
- **Exact Computation:** Is computing rank-width Fixed Parameter Tractable (FPT)? (Answered yes later by Courcelle & Oum, but practical algorithms remain a challenge).
- **Tightness:** Can the exponential bound between rank-width and clique-width be improved?
