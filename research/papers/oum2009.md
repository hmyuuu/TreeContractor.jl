# Analysis: Computing Rank-Width Exactly (Oum 2009)

**Paper:** "Computing Rank-Width Exactly"
**Author:** Sang-il Oum
**Year:** 2009 (Information Processing Letters)
**Task:** T-067
**Agent:** PhD-Algo

## 1. The Core Result
This paper provides an exact algorithm to compute the rank-width of an $n$-vertex graph in time $O(2^n \cdot n^3 \log^2 n \log \log n)$.
-   **Significance:** Before this, the trivial exact algorithm (iterating over all cuts) was roughly $O(3^n)$. This brings it down to $O(2^n)$, making it feasible for slightly larger graphs (e.g., $n=25-30$ vs $n=15-20$).

## 2. The Algorithm: Fast Subset Convolution
The key technique is **Fast Subset Convolution** (introduced by Björklund et al. for Set Cover/Partition).
-   **Problem:** We want to find a decomposition tree where every cut $(S, V \setminus S)$ has rank $\le k$.
-   **DP State:** Let $f(S)$ be a boolean indicating if the subgraph induced by $S$ admits a rank-decomposition of width $k$ where $S$ is a leaf of the partial tree (i.e., $S$ is one side of a valid cut).
-   **Transition:** A set $S$ is valid if it can be split into $S_1, S_2$ such that $f(S_1)$ and $f(S_2)$ are true, and the cut rank condition holds.
-   **Convolution:** The check involves iterating over all subsets $S_1 \subset S$. This looks like $3^n$.
-   **Improvement:** By defining appropriate polynomials/functions over the subset lattice, one can use Möbius Transform (or Walsh-Hadamard Transform) to perform the "subset sum" operations in $2^n \cdot \text{poly}(n)$.

## 3. Relevance to Our Solver
We currently rely on:
1.  **Heuristics:** $O(n^3)$ or $O(n^4)$. Fast but approximate.
2.  **Brute Force (Implicit):** Our `LocalSearch` doesn't prove optimality.
3.  **Future Feature:** An "Exact Mode" for small graphs ($n < 30$) would be very valuable for generating ground-truth benchmarks.

## 4. Implementation Feasibility
-   Implementing Fast Subset Convolution is non-trivial but well-documented.
-   It requires careful bit-manipulation.
-   **Action Item:** We could add a `exact_rank_width(G)` function using this algorithm for small $N$.

## 5. Conclusion
Oum (2009) is the definitive reference for the fastest known exact algorithm for general rank-width. It confirms that $2^n$ is the barrier to beat (and likely the limit due to ETH).
