# Visualization Style Guide

## 1. General Principles
- **Clarity:** Prioritize readability over aesthetics.
- **Consistency:** Use consistent colors and fonts across all plots.
- **Reproducibility:** All plots must be generated from code (CeTZ/Julia).

## 2. Color Palette (Academic Safe)
- **Primary Blue:** `#0072B2` (Okabe-Ito)
- **Primary Orange:** `#D55E00` (Okabe-Ito)
- **Neutral Grey:** `#999999`

## 3. Typography
- **Font:** Linux Libertine or similar serif for body text.
- **Math:** LaTeX standard.
- **Axis Labels:** 10pt minimum.

## 4. Plot Types
- **Comparison:** Bar charts with error bars.
- **Scaling:** Log-log plots for complexity analysis.
