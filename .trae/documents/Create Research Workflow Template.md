# Create Research Workflow Template

## 1. Directory Structure Creation
- Create a new root directory: `research_workflow_template`
- Create subdirectories:
  - `papers/`: For PDF/LaTeX and analysis notes
  - `code/`: For implementation (source, scripts)
  - `data/`: For datasets (raw, processed)
  - `docs/`: For workflow guides and supplementary info
  - `reviews/`: For peer feedback and notes

## 2. Template Files Generation
- **`README.md`**: Project overview, citation instructions, and directory map.
- **`LICENSE`**: Standard MIT License placeholder.
- **`.gitignore`**: Configured to ignore large data files, PDFs, and build artifacts.
- **Dependency Files**:
  - `requirements.txt` (Python placeholder)
  - `Project.toml` (Julia placeholder)

## 3. Documentation & Guides
- **`docs/workflow_guide.md`**: A generalized version of the current autonomous workflow, featuring:
  - Role-based responsibilities (Researcher vs. Implementer)
  - "Zotero First" literature search protocol
  - Structured paper analysis steps
  - Research-to-Code handover process

## 4. Example Content
- **`papers/template_analysis.md`**: A markdown template for analyzing papers (Summary, Key Theorems, Algorithmic Implications).
- **`code/src/placeholder.jl`**: A simple Julia module structure example.
